# 登录与岗位说明

## 管理平台

打开 https://api.yjr-adc-demo.xyz/，在“登录身份”中选一个教学岗位，输入登录页密码框下方显示的教学密码，然后点击“登录”。当前源码中的教学密码为 `ADCdemo8`，区分大小写；这个密码只用于公开演示资料，不能用于个人或正式工作账号。登录页可点“显示密码”核对输入。教学身份无需另找用户名，页面会自动选用对应教学账号。

| 页面选择 | 教学账号 | 可查看或办理的典型事项 |
| --- | --- | --- |
| 前台接待 | `reception` | 患者资料、预约、到诊、费用办理 |
| 牙医 | `dentist` | 本人接诊、临床记录、治疗接续 |
| 诊所主管 | `manager` | 门店资源、排班协调、需主管确认的事项 |
| 总部业务 | `business` | 多门店资源与业务管理 |
| 总部财务 | `finance` | 对账、财务复核和报表 |
| 总部负责人 | `director` | 连锁经营与授权范围内的管理事项 |

个人工作账号请选择“使用自己的账号”，填写由有权管理员开通的账号与原密码。切换登录身份会清空已输入的密码。岗位与门店权限由后端检查；选项本身不增加权限。

## 患者微信小程序

使用[患者体验二维码](../miniapp/微信1.5.2患者体验二维码.png)扫码。若体验码受微信成员权限或有效期限制，可由有权限的管理员使用[直接预览二维码](../miniapp/微信1.5.2患者预览二维码.jpg)核验；正式可搜索的小程序入口以微信实际审核发布为准。

在登录页点“账号密码登录”，选择“患者本人”或“监护人或授权代办人”。教学账号分别为 `patient`、`representative`，教学密码同上。页面也会显示教学账号和密码。选择“使用自己的账号”时，填写本人账号的独立密码。微信登录需要先同意隐私说明；未绑定的账号按页面完成绑定、注册或找回流程。

代办账号注册后须由门店核实具体患者、授权事项和有效期。紧急联系人不会自动成为代办人。教学资料为合成数据；请勿输入真实患者病历、证件或支付信息。

## 登录异常

1. 核对选的是教学身份还是“使用自己的账号”，并核对大小写与“显示密码”。
2. 教学账号使用登录页显示的当前密码；如果页面密码与此文档不同，以线上页面为准，说明云端教学密码已调整。
3. 小程序点“检查连接”。如果体验码无法打开，先确认扫码微信已加入体验成员，或使用有权限的管理员直接预览。
4. 个人账号失效、忘记密码或需要增加岗位范围时，走页面找回或联系有权人员；不要在公开 issue 中提交密码或患者资料。
